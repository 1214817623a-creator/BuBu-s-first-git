# 布布大王的菜谱 V1.1.0

本次包含内容扩容和筛选能力新增，按次版本发布为V1.1.0，Android构建号从1升为2。

## 更新内容

1. 支持多标签与多搜索词同时匹配，分类覆盖更多菜系、烹调方法和食材。
2. 新增100道不同菜品，总计106道；每道包含用量、火力与操作步骤、参考时间、完成判据及关联知识。
3. 新增300条知识，总计318条；新增条目均附机构名称与原文链接，覆盖31个权威资料页面。
4. 修订专业表达，区分家庭配比、口感判据与食品安全最低中心温度；知识操作建议单独呈现。
5. 用料数值与备注分开显示，修复盐、热水等长备注造成的右列断行。
6. 原创菜品示意插画按实际食材和成品形态绘制，区分整鱼、虾、排骨、叶菜、面条、饺子等；覆盖图与步骤图分离。
7. 列表分批加载，保留原有收藏、备料、计时和烹饪进度数据格式。

## 内容与验证

菜品参考美食天下热门分类、下厨房高参与度家常菜菜单、豆果热门分类，不宣称实时全网排名。步骤与配比为独立编写的家庭适配。知识依据USDA FSIS、FDA、FoodSafety.gov、USFA、WHO、香港食物安全中心与Iowa State University等机构资料整理，逐条索引在仓库 `docs/V1.1.0内容来源.md`。

静态分析、完整自动测试、菜品插画渲染、Android与Web发行构建均列入发布验收；具体结果见 `docs/V1.1.0验证记录.md`。

## 安装与限制

Android 7.0及以上。已有V1时直接覆盖安装，避免先卸载导致本地数据丢失。APK继续使用与V1相同的开发签名，供个人体验；安装包附SHA-256校验文件。

页面与流程通过自动测试和浏览器检查；未完成真实Android设备上的覆盖安装、后台通知、省电模式与常亮验证。这些系统行为需在实际手机上确认。烹调时间是参考，计时不能代替照看炉火。插画为菜品示意，非实拍。
